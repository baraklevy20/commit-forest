Commit Forest

Every day you contribute on GitHub plants a tree. Try it with your own username, pick a scenery, then put the forest on your profile with one workflow file.

Put it on your profile

  1. Your profile README lives in a public repository named after you. Open yours, or create it if you don't have one.
  2. Add this workflow as .github/workflows/forest.yml and commit it. Open it on GitHub, filled in.
  3. The workflow runs right away and takes a minute or two. Then paste this into your README.md:
Commit Forest is open source: github.com/baraklevy20/commit-forest. The forest is drawn by the engine of Memory Forest, an Anki add-on where study days grow the same trees. This page reads public contribution calendars through the free github-contributions-api.
